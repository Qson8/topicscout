# Two-week trial protocol & log template

- Start: 2026-11-08 · Review: 2026-11-22 (day 14)
- Internal subject: the author's blog dual list (domestic + overseas),
  published daily at blog.hanfucn.com/hot-keywords.
- External subjects: 5–10 real bloggers, invited by the author personally
  (invite script in `examples/creator-profile-template.md`). Aliases are
  fine in this log.

## Daily internal log

One line per day:

```
YYYY-MM-DD | keywords judged N | write-today N | queue N | drop N (one-line typical drop reason) | angles adopted as-written N
```

(Day 1, 2026-11-08, does not count as a sample: that day's list was prepared
and consumed before the skill existed. Logging starts 2026-11-09.)

## External log

```
subject (alias) | domain | start date | still using in week 2? | notes
```
