# Creator profile template

TopicScout judges (keyword × profile). Fill this once, reuse it every day.
Six short answers are enough. (The invite script below opens with a
three-question short version — domain, no-go zones, capacity — and the
full six are filled in once a trial actually starts.)

**Privacy rule for filled profiles:** a filled profile is the creator's own
working document. Keep it private (name it `*.local.md` and it stays out of
git); never commit someone else's filled profile — or their real name,
accounts, or contact details — to a public repository.

```markdown
## My creator profile
- **Domain & columns**: (e.g. 生活 / 人文 / 国风 / 技术, one article each per day)
- **Audience**: (who actually reads you — not who you wish read you)
- **Platforms**: (blog / Xiaohongshu / WeChat / TikTok … — format limits count)
- **No-go zones**: (e.g. no politics, no medical beyond common knowledge,
  no price predictions, no unverified allegations, no gear shilling)
- **Daily capacity**: (how many pieces you can really finish per day)
- **Standing columns**: (recurring features that fill slots without trend input)
```

Rules of thumb:

- Write the no-go zones **before** you see a tempting keyword. Zones written
  mid-temptation are not zones.
- Capacity is the honest number on a normal day, not your best day. The
  "write today" bucket is sized by it.
- If a judgment keeps hitting the same gap (a missing tag, a column that
  never matches), that is a profile bug report — surface it to yourself
  deliberately instead of letting the judge improvise around it.

# External trial — invite script (for the author's own use)

For inviting 5–10 real bloggers to the two-week trial. Keep it this plain;
do not promise a product timeline.

> 我在试一个选题判断的方法：每天把热榜词条对着你的账号画像过四道判断
> ——适不适合你写、能不能碰、还能热几天、怎么拆题——产出一张表：
> 今日就写 / 排队 / 放弃（带原因）。
>
> 想请你试两周。需要你先回答三个问题（你的领域和栏目、明确不碰什么、
> 每天能写几篇），之后我连着 3 天先发你判断表样例，你看着对味就继续，
> 不对味直接停，不用客气。
>
> 我只看一个结果：第二周你还愿不愿意每天先看它五分钟。

Log replies in `docs/TRIAL.md` (aliases only — never real names, platform
accounts, or contact details): domain, start date,
still using in week 2, notes.
